# arladkr Practical Hello World

A minimal, runnable Go example repository that serves as an independent Hello World starting point for `kase113/arladkr_Practicaladkr`.

## Run

Requires Go 1.26 or newer:

```bash
go run .
go run . ADKR
```

The commands print:

```text
Hello, World!
Hello, ADKR!
```

## Test

```bash
go test ./...
```
